# Networking basics #0

Introductory project on networking fundamentals: the OSI model, types of networks, MAC/IP addresses, TCP/UDP, ports, and checking whether a host is reachable.

## Resources

**Read or watch:**
- OSI model
- Different types of network (LAN, WAN, Internet)
- MAC address
- What is an IP address
- Private and public addresses
- IPv4 and IPv6
- Localhost
- TCP and UDP
- TCP/UDP ports list
- What is ping / ICMP
- Positional parameters

**man or help:**
- `netstat`
- `ping`

## Learning Objectives

At the end of this project, you should be able to explain, without the help of Google:

### OSI Model
- What it is
- How many layers it has
- How it is organized

### LAN
- Typical usage
- Typical geographical size

### WAN
- Typical usage
- Typical geographical size

### General
- What is the Internet
- What is an IP address
- What are the 2 types of IP address
- What is localhost
- What is a subnet
- Why IPv6 was created

### TCP/UDP
- The 2 main data transfer protocols for IP (transport layer of the OSI model)
- The main difference between TCP and UDP
- What is a port
- SSH, HTTP and HTTPS port numbers
- Which tool/protocol is often used to check if a device is connected to a network

## Requirements

- Bash script files
- Allowed editors: `vi`, `vim`, `emacs`
- All scripts are interpreted on Ubuntu 22.04
- All files end with a new line
- A `README.md` file at the root of the project folder is mandatory
- All Bash scripts must be executable
- Bash scripts must pass `shellcheck` without any error
- The first line of every Bash script is exactly `#!/usr/bin/env bash`
- The second line of every Bash script is a comment explaining what the script does
